# modpm-remove(1) -- Remove packages and the dependencies nothing else uses

## SYNOPSIS

`modpm remove` [<options>] <package>...

## DESCRIPTION

Removes packages, and the dependencies nothing else uses. Each <package> is the
slug or ID of an installed project.

## OPTIONS

  * `-y`, `--yes`:
    Don't ask for confirmation.

modpm(1)
